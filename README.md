# zekierman.me

A personal site built around one idea: **Chasing Light**.

It opens in darkness — a starlit field, a door standing open, light spilling out.
A seagull flies through it and the camera follows, out into an endless sea of
sunlit clouds. The journey is driven by scroll: the film advances as you move
down the page, and hands off to the site itself without a visible seam.

Not a CV. A place to walk around in.

## Stack

| | |
|---|---|
| Framework | [Astro](https://astro.build) 7, static output |
| Language | TypeScript (strict) |
| Styles | Tailwind CSS 4 + component-scoped CSS |
| Motion | [Lenis](https://github.com/darkroomengineering/lenis) smooth scroll, plain `requestAnimationFrame` for the hero |
| Fonts | Archivo + Instrument Serif, self-hosted and subset by Astro's fonts API |

No animation framework. The hero scrub is a short rAF loop over refs — a
reconciler between the scroll position and `video.currentTime` would only add
latency to the thing that most needs none.

## Languages

English lives at the root, Turkish under `/tr`. The apex keeps its link equity
and shared URLs stay clean. Copy is not translated line-for-line — both versions
are written natively and live side by side in `src/content/copy.ts`.

## Layout

```
assets/            master footage and stills — gitignored, never modified
public/media/      web derivatives, generated by tools/encode.sh
src/
  components/      Hero, Arrival, LangSwitch, SmoothScroll
  content/copy.ts  all site copy, both languages
  layouts/         Base — head, SEO, hreflang
  pages/           index.astro (en), tr/index.astro
  styles/          global tokens
tools/encode.sh    regenerates public/media from the masters
```

## Development

```bash
npm install
npm run dev        # localhost:4321
npm run check      # astro check + tsc
npm run build      # static output to dist/
npm run preview
```

## Media

`public/media/` is generated, not authored. To rebuild it from the masters:

```bash
bash tools/encode.sh
```

The masters are large and stay out of git. The script carries the reasoning for
its encoder settings — in short, the source film ships one keyframe for the whole
clip, which makes scroll scrubbing decode from frame zero on every seek. The
derivatives are cut with a short GOP and no B-frames so a seek costs a few frames
instead of the entire film.
